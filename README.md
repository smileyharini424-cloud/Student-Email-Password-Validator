STUDENT EMAIL & PASSWORD VALIDATOR

🚀 PROJECT OVERVIEW

The Student Email & Password Validator is a web-based mini project developed using HTML, CSS, and JavaScript, based on concepts from Automata Theory and Deterministic Finite Automata (DFA).

The application validates a student's college email address and password according to predefined rules. It also displays the DFA state path and provides a final ACCEPTED or REJECTED result.

🤖 DFA CONCEPT

The project demonstrates the concept of a Deterministic Finite Automaton (DFA) through state transitions during validation.

DFA State Path:

q0 → q1 → q2 → q3 → q4 → q5

Where:

q0 → Start State
q1–q4 → Intermediate States
q5 → Accepting State
Dead State → Invalid Input

The application visually highlights the DFA states during the validation process.

🎯 FINAL RESULT

When both the email and password satisfy the required conditions:

🎉 FINAL RESULT: ACCEPTED

If either the email or password fails validation:

❌ FINAL RESULT: REJECTED
